# Frontend stack: Vite + React + TypeScript + Tailwind + shadcn/ui, light theme

The demo is a pure client-side single-page app with dummy data and no backend, so it uses **Vite + React + TypeScript** rather than a heavier SSR framework (Next.js). **Tailwind + shadcn/ui** provide the accessible primitives (card, dialog, drawer, badge, command) the UI leans on.

The visual direction is a **light, modern, minimal** theme (white canvas, slate neutrals) with **indigo** reserved for AI moments and a **green / red / amber** outcome triad, informed by a reference screen the recruiter supplied (its visual language, not its layout). Full design language in [UX.md](../UX.md).
